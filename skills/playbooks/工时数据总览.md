# 工时数据总览（工时投入结构可视化）【只读】

> 一句话：在工时花费统计的「工时数据总览」视图查看某时间段工时投入结构——总花费/标准、项目/非项目、请假与日常管理、任务类型分布、请假类型分布、工时投入 TOP5，并可点扇区/柱状下钻明细。V2.3.0 新增真实模块（原为前端 Mock 演示页）。

- **入口**：统计 → 工时花费统计（`/statistic/export_estimate`）→ 双视图切「工时数据总览」（顶部「每日工作概览 / 工时数据总览」+ 旁「点击切换」）
- **路由**：`/statistic/export_estimate`
- **适用/触发**：定时/周期性统计团队工时投入结构（如每月看任务类型/请假分布/项目 TOP5）

## 操作步骤（真实 UI）

1. 导航 `/statistic/export_estimate`，等表格/面板渲染；关公告
2. 切到「工时数据总览」视图（点顶部「工时数据总览」文字，或 vm `estimate/index.vue` 的 `setNav({name:'工时数据总览'})`）
3. 设日期范围 + 可选筛选（花费人/部门/项目）→ 点「搜索」
   - ⚠️ 日期是 el-date-picker，自动化直改 input 会触发内部报错；走组件 `HourOverviewPanel.query.start_date/end_date` + `loadData()`
   - ⚠️ 主组件 `search()` 会把 overviewQuery 日期重置回今天，勿用它设日期
4. 读指标卡与图表；点扇区/柱状下钻：
   - 任务类型环形图扇区 → 「二级任务选项工时占比」弹窗 → 「查看全部明细」→ 工时明细弹窗
   - 项目与非项目占比扇区 → 产出占比；请假柱状 → 请假明细

## 可直调接口（免 UI 快路径）

- 总览数据加载在前端组件 `HourOverviewPanel.loadData()`（driven by `query.{start_date,end_date,user_ids,dept_id,confirm_status,project_type}`）；定时统计可在页面内 driven vm：
  ```js
  // 页面已登录后：
  const panel = /* 找 __file 含 HourOverviewPanel 的 vm */;
  panel.query.start_date='2026-06-01'; panel.query.end_date='2026-07-27';
  await panel.loadData();
  panel.summary; // {total, daily_avg, standard, project, not_project, leave, daily_manage}
  panel.taskTypeRaw; panel.projectRatio; panel.leaveDist; panel.projectTop5; panel.notProjectTop5;
  ```
- 明细导出（每日工作概览侧，携当前筛选所见即所得）：`GET /manage_api/data_export/export_daily_estimate?start_date=&end_date=&userList=&dept_id=&export=1`（返 xlsx）

## 读数 / 断言锚点

- 指标卡：总花费/标准工时、项目、非项目、平均每日花费、请假与日常管理（请假/日常管理分项）
- 图表标题：「任务类型花费工时分布」「项目与非项目工时占比」「请假工时类型占比」「项目/非项目工时投入 TOP5」
- 下钻弹窗：「「{任务类型}」二级任务选项工时占比」「工时明细 — 任务选项：{名}」（表头 部门/项目·非项目/类型/需求/任务/任务选项/产出类型/花费工时/任务标准工时/确认状态/备注/日期/花费人）
- **数据自洽校验**：total = project + not_project；请假与日常管理 = leave + daily_manage；leave = 各请假类型段和；一级任务类型值 = 其二级 children 段和

## 陷阱

- ⚠️ el-date-picker 直改 input 报错，走 vm.query + loadData。
- ⚠️ 主组件 `search()` 重置日期回今天。
- ⚠️ 每日工作概览列表接口是 `export_daily_estimate_old`（返 demand_name/demand_nature），`export_daily_estimate` 是 xlsx 导出——别混。
