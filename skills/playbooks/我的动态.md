# 我的动态（个人相关动态集中管理）【写】

> 一句话：在"我的动态"集中查看/筛选与自己相关或站点全部的会议、风险、问题动态，并快速添加项目动态。

- **入口**：我的地盘 → 我的仪表盘「相关项目动态」结果卡（点击跳转）→ 左栏「与我有关 → 我的动态」
- **路由**：`/my_board/main/moments`（直接 URL 会重定向回 main，点左栏菜单进入）
- **适用/触发**：全员集中盘点/跟进与自己相关及站点范围的会议/风险/问题动态；快速新建动态

## 操作步骤（真实 UI）

1. 进 `/my_board/main/main`，等 `li.el-menu-item` 出现；仪表盘「相关项目动态 N 条」为结果记录卡
2. 点该结果卡 → 真实路由到 `/my_board/main/moments`（或点左栏 `.el-menu-item:has-text("我的动态")`）
3. 筛选：顶部「全部 N / 会议 N / 风险 N / 问题 N」计数标签；「全部动态（站点全部）/ 与我相关（个人相关）」切换；「按项目搜索」输入框
4. 快速添加：点「添加动态」→ 弹窗顶部「所属项目」远程搜索选项目 → 选「会议动态/风险动态/问题动态」tab → 填必填 → 「提交」
   - 问题动态必填：问题类型 / 问题描述 / 影响程度（低/中/高）/ **问题关注人员**（远程搜索 el-select）
   - 会议动态必填：会议类型 / 会议内容 / 参会人员；可加待办事项（含负责人+状态）
5. 读结果：动态按月分组卡片渲染（项目名/类型/影响/内容/相关人员/日期）

## 可直调接口（免 UI 快路径）

- `GET /manage_api/project_moment/get_list?module=meet|risk|problem&project_id=N`（Laravel 分页，列表在 `data.data`；不传 project_id 返跨项目全量）
- `POST /manage_api/project_moment/add`：`{type, content, module:'meet'|'risk'|'problem', project_id, risk_level(影响程度), status(解决状态), user_ids(关注人员), remark(会议待办JSON串)}`
  - 幂等造数助手 `ensureProblemMoment` / `ensureMeetingMoment`（helpers.js）

## 读数 / 断言锚点

- 筛选计数：innerText 含 `会议 \d`、`风险 \d`、`问题 \d`
- 视野切换：innerText 含「全部动态」+「与我相关」
- 添加入口：`button:has-text("添加动态")`；搜索：`input[placeholder*="按项目搜索"]`
