# 我的工作台-51PM Agent配置【只读】

- 入口：顶栏「我的工作台」下拉 →「51PM Agent配置」，路由 `/ai_api_key_config`
- 用途：个人配置 AI 大模型 API Key + 选择默认使用模型，供产能诊断（[产能数据看板](产能数据看板.md)）、测试数据总结等全站 AI 能力调用；未配置或未生效时对应 AI 功能不可用。
- 页面结构：页头说明文案 + 「刷新」「新增 API Key」按钮；已配置 Key 以卡片展示（名称/Base URL/掩码 Key/默认模型下拉/生效状态徽章/最近校验时间/复制·编辑·刷新模型·删除操作）。
- 「新增 API Key」弹窗：3 种接入方式单选——
  1. 公司配发 n1n 平台（消耗公司承担）
  2. 公司配发 OpenRouter 平台（消耗公司承担，含免费模型）
  3. 私人第三方或官方密钥（费用自行承担）
  选中方式后自动带出对应 Base URL；必填密钥名称（30字限）+ Base URL + API Key；「测试连接并获取模型」拉取可用模型列表，失败可手动填写。
- 接口：`ai_api_key/get_ai_api_key_list`。
- 验收记录：V2.3.1 补充验收（2026-08-12），见 [acceptance-report.md](../../acceptance/V2.3.1/acceptance-report.md) §9。仅验证了已有配置的展示/编辑入口与新增弹窗静态呈现，未走完整新增/删除写链路，也未验证"未配置时功能不可用"的反向门禁。
