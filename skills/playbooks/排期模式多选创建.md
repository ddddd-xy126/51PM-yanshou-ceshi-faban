# 排期模式-拖动多选连续单元格快速创建【写】

> 一句话：在排期表进入「排期模式」后，拖动鼠标选择同一行的连续单元格，一次性快速创建项目/非项目任务的排期。典型 AI 复用场景：给某人连续多日批量排任务。
>
> ⚠️ **写操作**：拖选后会弹快速创建任务表单并落库；提交前把「人员 + 日期区间 + 任务」给用户 AskUserQuestion 确认。

## 参数

| 参数 | 示例 | 说明 |
| --- | --- | --- |
| `env` | `test`（默认） | 测试 `10.67.8.183:7777` |
| `person` | `邓欣羽` | 目标人员行 |
| `date_from`~`date_to` | `2026-08-01`~`2026-08-05` | 同一行的连续日期区间 |

## 入口

- **入口**：排期 → 排期表 →「进入排期模式」按钮
- **路由**：`/schedule/schedule_table`
- **等待锚点**：`waitForTimeout(3000)`（排期表渲染慢）
- **进站**：先按 [../README.md](../README.md) Tab 复用

## 操作步骤（真实 UI）

1. `goto /schedule/schedule_table`，等表格渲染
2. 点「进入排期模式」→ 弹提示「已进入多选模式，可以拖动鼠标选择同一行的连续单元格」，按钮切「退出排期模式」
3. 在目标人员行内，鼠标 `mousedown` 起格 → `mousemove` 跨连续格 → `mouseup` 终格 → 弹快速创建任务表单
4. 填任务信息（项目/需求/产出类型/工时等）→ 提交 → 对所选连续时段落库排期
5. 完成点「退出排期模式」（弹「已退出多选模式」）复原

## 步骤

### 1. 进入排期模式（模式切换）

```js
[...document.querySelectorAll('button')].find(b=>b.innerText.trim()==='进入排期模式')?.click();
// 断言：body 含「拖动鼠标选择同一行的连续单元格」且出现「退出排期模式」按钮
```

### 2. 拖选同一行连续单元格（Playwright 鼠标手势，坐标模拟）

```js
// 拖选是 mousedown→move→up 连续手势，evaluate 合成 click 无效；用 Playwright mouse API 走真实坐标
const from = await cellRect(person, date_from);  // 取起格 getBoundingClientRect 中心点
const to   = await cellRect(person, date_to);    // 取终格
await page.mouse.move(from.cx, from.cy); await page.mouse.down();
await page.mouse.move(to.cx, to.cy, { steps: 8 }); await page.mouse.up();
// → 弹快速创建任务表单，填字段后提交
```

### 3. 退出复原

```js
[...document.querySelectorAll('button')].find(b=>/退出排期模式/.test(b.innerText))?.click(); // 弹「已退出多选模式」
```

## 🚨 防手滑（写操作强制）

- 拖选跨格会一次创建**多格排期**，务必先确认人员/日期区间；提交前 AskUserQuestion
- 退出务必点「退出排期模式」还原，避免影响后续单格操作
- 拖选是鼠标连续手势，spec 自动化只稳断言「模式进出 + 提示文案」，实际拖选创建建议真人或精确坐标 mouse API

## 可直调接口（免 UI 快路径）

- 排期数据属 `schedule` 命名空间（`schedule/schedule_table` 取数）；纯前端模式切换无独立接口，创建走排期已有链路

## 读数 / 断言锚点

- 模式激活：`button:has-text("退出排期模式")` 可见 + body 含「拖动鼠标选择同一行的连续单元格」
- 模式退出：body 含「已退出多选模式」

## 已知坑

- ⚠️ 纯前端模式切换，无独立接口；退出务必还原
