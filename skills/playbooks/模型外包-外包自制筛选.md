# 模型外包-外包/自制筛选【只读】

> 一句话：在模型外包列表用"外包 / 内部自制"对称筛选，分别查看外包与自制发包。

- **入口**：项目 → 项目详情 → 模型外包 → 列表筛选 radio（全部 / 外包 / 内部自制）
- **路由**：`/project/outsource_project?projectId=N`
- **适用/触发**：DTA/PM 分别盘点外包与自制发包进度、明细

## 操作步骤（真实 UI）

1. 导航到 `/project/outsource_project?projectId=N`，等 `.el-table` + 筛选 radio 出现
2. 点 `.el-radio-button__inner`：`全部` / `外包` / `内部自制`（外包与自制对称）
3. 读结果：列表按承接方式过滤，`共 N 条` 联动

## 可直调接口（免 UI 快路径）

- `GET /manage_api/outsource/get_package_list?page=1&limit=10&sj_num=<商机号>&is_self_made=0`
  - `is_self_made=0` = 外包；`is_self_made=1` = 内部自制；不带该参 = 全部
  - 发包记录字段：`is_self_made`（0外包/1自制）、`self_made_uid`/`self_made_dept_name`（自制）、`supplier_name`（外包供应商）、`status`（4制作中/5已结项/6已取消/8挂起）
  - 响应列表在 `data.data` 或 `data`
- 定时任务：按 `is_self_made` 直接拉外包/自制两组

## 读数 / 断言锚点

- 筛选 radio：`.el-radio-button__inner`（文本 全部/外包/内部自制）
- 列表主体：`.el-table__body tr`
- 总数：`共 (\d+) 条`

## 已知坑

- ⚠️ 某项目可能只有外包或只有自制发包，对应档显 0 条属正常
- ⚠️ 列表内联「编辑」只改外包代号，完整表单在固定右列 `.el-table__fixed-right` 的「编辑」
