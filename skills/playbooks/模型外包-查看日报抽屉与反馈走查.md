# 模型外包-查看日报抽屉与反馈走查【写】

> 一句话：发包列表「查看日报」已由弹窗重构为右侧**抽屉 + 摘要态卡片**（日报再多也能一眼扫重点）；抽屉内可对某模型任务「快捷添加新反馈」（批量创建向导）、点「N条反馈」进「反馈走查单」留下「反馈走查留言」，留言在该发包的反馈管理-验收工作台批量验收时可查看。V2.3.2 新增/重构（源反馈：场景组"日报弹窗展示空间过大、可视密度低"）。

- **入口**：项目 → 项目详情 → 模型外包 → 发包列表行内「查看日报(N)」→ 右侧抽屉「模型制作日报」
- **路由**：`/project/outsource_project?projectId=N`（发包详情走 `/project/outsource_detail?outsourcePackageId=N`）
- **适用/触发**：查看某发包各模型的制作日报进度、对模型发起反馈、就反馈进行走查留言协作；验收工作台批量验收时参考走查留言

## 参数

| 参数 | 示例 | 说明 |
| --- | --- | --- |
| `projectId` | `6679` | 半导体项目（发包#31 有 46 条日报，样本充足）；运行时按项目名经 `get_project_list` 解析，或 `get_package_list` 取 `report_count>0` 的发包 |
| `outsource_package_id` | `31` | 目标发包 |
| `outsource_task_id` | `195` | 抽屉内某模型任务（走查留言/反馈按任务归属） |

## 操作步骤（真实 UI）

1. 导航到 `/project/outsource_project?projectId=N`，等 `.el-table` 出现
2. 在目标发包行「制作日报」列点「查看日报(N)」→ 打开右侧 `.el-drawer`「模型制作日报」
3. **抽屉浏览**：顶部「搜索模型/建筑名称」+ 状态筛选；主体 `.pdrd-task-card` 摘要卡（模型代码/建筑标签/状态点/制作方/N条日报/N条反馈/「添加新反馈」）；点卡头折叠箭头（`.pdrd-task-card__head`）展开见紧凑日报行（日期/制作方/进度条%/内容摘要）
4. **快捷添加反馈**：任务卡点「添加新反馈」→「批量创建反馈」向导（两步）：
   - 步骤1 录入条目（默认 5 条占位，可「新增反馈」）：每条选 反馈模块*（规范/模型/UV/材质）+ 反馈内容* + 截图（可选 Ctrl+V 贴图）；填全「已完善」，「下一步（N/5）」启用
   - 步骤2 确认提交：核对「即将提交 N 条反馈，统一归属该任务」→「确认提交 N 条」→ toast「成功创建/反馈已提交」
5. **反馈走查留言**：任务卡点「N条反馈」chip → 打开「模型反馈走查单」（`TaskFeedbackDialog.vue`）：左侧反馈记录（问题说明/处理结果/状态/提交人），右侧「反馈走查留言」区 → 输入「写下你的验收建议…」（≤500 字）→ 出现「发布」→ 点「发布」→ toast「验收建议已发布」，留言即时上屏（作者/时间/内容）
6. **验收工作台查看留言**：发包详情 → 反馈管理 tab →「验收工作台」（仅拉待验收 quality_status=2）→ 每条反馈头部「查看反馈走查留言 N」按钮悬浮 → popover 展示该任务全部走查留言

```js
// 打开抽屉
document.querySelector('td .cell a, button')?.innerText; // 找「查看日报(N)」
[...document.querySelectorAll('*')].find(e => /查看日报\(\d+\)/.test(e.innerText) && e.children.length===0)?.click();
// 快捷添加反馈
const drawer = document.querySelector('.el-drawer');
const card = [...drawer.querySelectorAll('.pdrd-task-card')].find(c => c.innerText.includes('有机通风柜'));
[...card.querySelectorAll('button')].find(b => b.innerText.includes('添加新反馈')).click();
// 反馈走查单
[...card.querySelectorAll('[class*=chip]')].find(c => /条反馈/.test(c.innerText)).click();
```

## 可直调接口

- `GET /manage_api/outsource_task/get_task_list?outsource_package_id=N` → 抽屉任务列表
- `GET /manage_api/outsource_daily_report/get_daily_report_list?outsource_task_id=N&page=1&limit=999` → 逐任务日报
- `GET /manage_api/outsource_task/get_feedback_suggestion_list?outsource_task_id=N` → 反馈走查留言列表（读）
- `POST /manage_api/outsource_task/create_feedback_suggestion` body `{outsource_task_id, content}` → 发布走查留言（写）
- `POST /manage_api/outsource_feedback/create_feedback` body `{outsource_package_id, outsource_task_id, feedback_module, feedback_content}` → 快捷添加反馈（写，新建 quality_status=0）
- `GET /manage_api/outsource_feedback/get_feedback_list?outsource_package_id=N&quality_status=2` → 验收工作台队列（仅待验收）

## 已知坑

- ⚠️ 快捷添加反馈成功后，抽屉任务卡「N条反馈」计数**不实时刷新**（仍显旧值，关闭并重开抽屉才更新为正确值）；反馈本身已正确落库（V2.3.2 轻微缺陷 B3）
- ⚠️ 走查留言输入框在输入内容后才出现「发布」按钮（空内容无按钮）
- ⚠️ 验收工作台仅拉 `quality_status=2` 待验收反馈；未受理(0)/已验收(3) 不在队列，空队列 toast「当前没有待验收的反馈」不打开工作台
- ⚠️ 反馈走查单/走查留言按**任务（outsource_task_id）**归属，不是按单条反馈——同任务的多条反馈共享一份走查留言列表
