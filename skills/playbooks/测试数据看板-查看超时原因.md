# 测试数据看板-查看超时原因【只读】

> 一句话：在测试数据看板递交明细里查看某项目本次超时递交的原因说明。

- **入口**：统计 → 测试数据看板 → 点递交相关卡片（如「超时递交 N 项」）打开递交明细弹窗 → 明细行「查看超时原因」按钮
- **路由**：`/statistic/bug`
- **适用/触发**：PM/QA 盘点递交数据时定位超时缘由

## 操作步骤（真实 UI）

1. 导航到 `/statistic/bug`，等页面渲染、关公告弹窗
2. 切统计周期到含超时数据的区间：点 `.el-radio-button__inner`「季度」（如 2026 Q3 有 4 条超时）
3. 点「超时递交 N 项」卡片（`*` 中 innerText `^超时递交\d+项` 的可点容器）→ 弹「明细 — 超时递交」弹窗（表列：项目/递交状态/递交版本/计划递交时间/实际递交时间/PM/超时递交/延期责任人/责任岗位/临时原因）
4. 点某行「超时递交」列的 `button:has-text("查看超时原因")` → 弹「超时原因」弹窗（项目名 + 原因说明文字 + 截图）
5. 读结果：`.el-dialog` 中含「超时原因」标题 + 项目名 + 原因文本

## 可直调接口（免 UI 快路径）

- 递交超时明细走 `data_export/get_qa_stat_detail_list`（chart_key=over_tb；参数口径以页面请求为准，超时原因随记录返回）
- 环比/概览：`data_export/get_qa_stat_{kpi,bug,publish,summary}`

## 读数 / 断言锚点

- 明细弹窗：`.el-dialog` innerText 含「明细 — 超时递交」
- 超时原因按钮：`button:has-text("查看超时原因")`
- 原因弹窗：`.el-dialog` innerText 含「超时原因」+ 项目名 + 原因段

## 已知坑

- ⚠️ 当前统计周期无超时记录则卡片/明细为空、无「查看超时原因」按钮 → 先切到有数据的周期
- ⚠️ 看板超时按**实际递交时间**归入统计周期（计划在上一周期、实际落本周期的记录计入本周期），与按计划时间筛选的递交列表口径不同（口径待产品确认）
