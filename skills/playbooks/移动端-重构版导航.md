# 移动端（重构版）【只读/写】

> 一句话：移动端重构后的入口与核心页导航，供移动端工时/递交类日常操作与截图复用。

- **入口**：移动端 `/mobile`（自动进 `/mobile/home`）
- **路由**：`/mobile/home` 首页 · `/mobile/createEstimate` 填工时 · `/mobile/projectDaily` 日报 · `/mobile/tb_publish` 申请
- **适用/触发**：移动端填工时、看日报、申请递交等日常操作；移动端截图/回归

## 操作步骤（真实 UI）

1. 移动视口打开 `/mobile`（headless 用 `viewport:{width:390,height:844}, isMobile:true, hasTouch:true`；集成浏览器 `setViewportSize(390,844)`）
2. 首页 `/mobile/home`：
   - 工时确认卡（今日已确认 Xh / 8h 目标 + 环形进度 + 达标/未达标）+ 今日已创建 / 本月休假 统计卡
   - 「确认今日工时」CTA、快捷功能宫格（填工时/创任务/申请递交/项目日报/帮TA补工时）
   - 底部导航：首页 / 填工时 / 日报 / 申请（`nav a[href]`，href=各 `/mobile/*` 路由）
3. 填工时 `/mobile/createEstimate`：项目任务 / 非项目任务 tab（`[role=tab]` 点击切换）+ 今日开始 / 已完成 筛选 + 任务卡「填写工时」+ 分页
4. 日报 `/mobile/projectDaily`：项目日报列表（真实项目 + SJ 号）
5. 申请 `/mobile/tb_publish`：我的递交申请 / 项目递交排期 tab（卡片含 审批中/已排期 状态、要求递交时间、申请时间）+ FAB 新建按钮

## 陷阱

- ⚠️ 截图必须移动视口（390×844），别用 1920（会拍成 PC 布局残影）；headless `isMobile:true`
- ⚠️ 移动端复用既有 PC 后端接口，鉴权同走 Bearer oauthToken；无独立移动端后端契约
- ⚠️ 子页直接改 URL 一般可达（本轮实测 /mobile/createEstimate 等直达正常）；若被重定向回 home，改从底部导航点入
- ⚠️ 移动端为整体重构，页面较多，回归/验收只覆盖 4 核心页 + tab/筛选/分页交互，未穷举每屏与写链路提交
