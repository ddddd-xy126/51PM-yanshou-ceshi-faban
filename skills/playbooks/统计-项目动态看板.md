# 统计-项目动态看板【只读】

> V2.3.1 补充（2026-08-08）。会议/风险/问题三类项目动态的周期性全景看板，支持卡片/图表下钻明细 + 多维筛选。源头表 `project_moment`（module=meet/risk/problem）。
> **V2.3.3 追加「项目成本动态」tab**（同页第三个 tab，见文末「项目成本动态（V2.3.3）」一节）。
> 通用前置见 [README.md](README.md)（登录态/环境/参数解析硬规则）。

## 入口

- 路由 `/statistic/project_risk_panel`（统计菜单 → 项目动态看板）
- 三 tab：「项目动态看板」（卡片+图表）/「动态明细」（列表，点"点击切换"）/「**项目成本动态**」（V2.3.3 新增，见文末专节）

## 可直调接口（定时/批量任务优先走这里，UI 是兜底与验证）

| 用途 | 接口 | 关键参数 / 说明 |
|---|---|---|
| 卡片+图表聚合 | `GET data_export/get_project_moment_stat` | `period_type=day/week/month/quarter/half_year/year` + `period_key`（年`2026` / 周`2026-W32` / 月`2026-08`）+ `module=all/meet/risk/problem` + 可选 `pm_id=<PM用户id>`、`sj_num=<商机号>`；返 `data.{period, summary, risk, problem, meet}` |
| 动态明细列表 | `GET data_export/get_project_moment_stat_list` | 同上 period/module + `page&limit`；Laravel 分页（列表在 `data.data`，总数 `data.total`） |
| 源头对账 | `GET project_moment/get_list` | `module=meet/risk/problem&page=1&limit=9999`（无 project_id 返跨项目全量，列表在 `data.data`）；按 `create_time` 落入统计周期自行分组即得看板数字 |

- 鉴权：`Authorization: Bearer <oauthToken>`（页内 fetch 直连 `http://10.67.8.189:8888/manage_api/...` 可用，后端放 CORS）。

### summary 结构（卡片）
```
summary.{risk|problem|meet} = { value, prev_value, delta_rate, breakdown:[{name,count}] }
```
- risk breakdown 按等级（高风险/中风险/低风险）；problem 按问题类型；meet 按会议类型。

### 图表数据结构
- `risk.type_level_list[]`={name(风险类型),high_num,medium_num,low_num}；`risk.creator_level_list[]`（PM 创建×等级）；`risk.creator_type_list[]`（PM 创建×类型）
- `problem.type_level_list[]`（类型×影响 high/medium/low）；`problem.creator_level_list[]`（发起人 TOP10×影响）；`problem.dept_type_list[]`（部门×类型）
- `meet.type_dist_list[]`={name,count,ratio}；`meet.creator_type_list[]`（PM 创建×类型）

## 操作流程（UI）

1. goto `/statistic/project_risk_panel`，`waitForTimeout(5000)`，关公告 `dismissAnnouncement`。
2. **切统计周期**：`.el-radio-button__inner` 文本精确匹配点击（天/周/月/季度/半年/年）。切后旁边日期选择器变对应粒度（选年/周/月）。
3. **切动态类型**：定位含"会议""问题"的 `.el-radio-group`，点其中 `.el-radio-button` 文本=全部/会议/风险/问题 的 `.el-radio-button__inner`。切后卡片+图表+明细实时刷新，聚合请求携 `module=`。
   ```js
   await page.evaluate(() => { const gs=[...document.querySelectorAll('.el-radio-group')]; for(const g of gs){ if(g.innerText.replace(/\s/g,'').includes('会议')&&g.innerText.includes('问题')){ for(const b of g.querySelectorAll('.el-radio-button')){ if(b.innerText.trim()==='问题'){ b.querySelector('.el-radio-button__inner').click(); return; } } } } });
   ```
4. **更多筛选**：点「更多筛选」按钮 → popover 含 所属项目/项目经理/相关人/相关部门/动态发起人 el-select；选项目经理某人 → 聚合请求携 `pm_id=<id>`、出现筛选标签「PM：X」；「重置」清空。
5. **卡片下钻**：点"本期新增问题/风险/会议"卡片（`cursor:pointer` 容器）→ 全屏抽屉「本期新增X明细（N条）」（左侧影响程度/等级环形图+统计，右侧按类型 tab 筛选、按月分组卡片）。
6. **图表下钻**：ECharts canvas，点柱段/扇区 → 「明细 — 「类型」等级明细」弹窗（表格：项目/动态/类型/等级·影响/内容摘要/PM/创建人/创建部门/创建时间）。柱段坐标点击极不稳（`echarts_instance` 属性只是字符串 key，`el[key]` 拿不到实例，`window.echarts` 也非全局，无法读 `getOption()` 定位坐标）；**可靠做法**：①先移开鼠标（避免 hover 高亮污染像素）②`canvas.getContext('2d').getImageData()` 按列/行扫描颜色分段找到目标类别的像素区间 ③在分段中点 `page.mouse.click()`。用 `axis` 触发的 tooltip（hover 即出，不需点击）可先低成本核对整条类别的数值分布是否与源头一致，再挑值点击验证弹窗条数。V2.3.1 补充验收已用此法把风险/问题/会议三维度全部 8 张图表 + 3 张卡片逐一点击验证，弹窗条数与图表段值、源头分组三方一致。
7. **动态明细 tab**：点顶部「动态明细」→ 列表（同上表格列，`get_project_moment_stat_list`，分页 25/页）；继承当前周期+动态类型筛选。

## 读数锚点（数据正确性校验）
- 卡片 value == breakdown 分组加总 == 各维度图表该模块加总
- 风险 type_level_list 每类 high+medium+low 之和 == 该类源头 `project_moment` 数量
- 动态明细 全部 total == 风险 total + 问题 total + 会议 total
- **跨模块对账**：`project_moment/get_list?module=X&limit=9999` 按 create_time 落期分组 == 看板 summary.X.value（周/年实测逐维度一致）

## 陷阱
- ⚠️ **风险等级/风险类型/解决状态/搜索项目/TB·BD/开工时间/创建时间 筛选属下钻抽屉内**，不是主看板筛选栏（主看板只有 统计周期+动态类型+更多筛选+重置）；别在残留抽屉 DOM 上操作误判"主看板筛选不生效"。
- ⚠️ PM 筛选参数名是 `pm_id`（不是 project_pm）；`get_project_moment_stat` 不认 project_pm/risk_level/sj_num 之外的乱参（乱试参数名会误判"参数不生效"）。
- ⚠️ 风险 `risk_level` 存全词「高风险/中风险/低风险」（问题存「高/中/低」）——源头对账按等级分组要用 includes 归一，别精确匹配"高/中/低"（否则风险计 0）。
- ⚠️ `get_project_risk_panel` 是**风险聚合面板**接口（返 high_risk_num/pm_risk_list/type_risk_list，非明细数组），与看板主接口 `get_project_moment_stat` 不是一回事。
- ⚠️ 测试环境数据实时漂移（开发活跃），对账要看板与源头**同一时刻**取数比较。
- 出定妆图用 headless + storageState（集成浏览器视口回弹）；charts 需 `waitForTimeout` 待 ECharts 布局后再截。

## 项目成本动态（V2.3.3 新增）

> 同页第三个 tab，`标准/花费/产出/非产出/范围扩张` 五维成本视图；不写 `project_moment`，独立接口 `data_export/get_project_cost_stat`。

### 可直调接口

| 用途 | 接口 | 关键参数 |
|---|---|---|
| 成本总览/明细聚合 | `GET data_export/get_project_cost_stat` | `period_type=day/week/month/quarter/half/year`（⚠️半年取值是 `half` 不是 `half_year`，真机实测）+ `period_key`（**必填**，留空返业务码 51「请选择统计周期」；格式 day=YYYY-MM-DD/week=YYYY-Www/month=YYYY-MM/quarter=YYYYQn/half=YYYYHn/year=YYYY）+ `pm=<项目经理id>` + `project_id=<项目编号，如SJ202605120002，注意非数字库id>`（pm/project_id 可留空=全部）；`group` 参数含义未探明（本轮未验证其取值影响） |
| 跨模块对照（成本预警） | `GET project_overview/get_header?project_id=` | `data.cost_compare.{algoA.actualHours 实际花费, algoB.outputDays 产出类型工时}`，可与本接口「产出类需求花费」「产出工时EV」对照（详见下方陷阱） |
| 跨表源数据对照 | `GET project/get_project_list` | 同项目行 `standard_hour/consumed_hour/origin_hour/new_hour/change_hour/done_hour` 六项应与看板 标准/花费/初始/新增/变更/产出 逐项相等 |

### 操作流程（UI）

1. goto `/statistic/project_risk_panel`，`waitForTimeout(5000)`，关公告 `dismissAnnouncement`。
2. 点顶部第三个 tab「项目成本动态」。
3. **筛选**：统计周期（天~年）+ 项目经理 `pm` + 项目 `project_id`，均实测生效（切统计周期「共 X 个项目」随开工日期变化；筛项目经理/项目精确收窄）；「重置」清空恢复默认。
4. **视图切换**：「成本总览」（健康矩阵气泡图 + 环形图 + 堆叠条形图 + 可展开明细区块）/「项目明细」（列表逐项目一行）。
5. **成本画像下钻**：点「成本健康矩阵」气泡 或 项目明细行「成本画像」按钮 → 同一弹窗组件（已验证等价）→ 指标卡 + 命中告警 + 工时去向线索（人员/任务类型/需求归属 TOP5）+ 原始工时填报明细下钻 + 单项目 AI 分析入口。
6. **可展开明细区块**：「范围扩张明细」「管理/反馈成本明细」两个展开区块，逐行工时加总应与总览对应 headline 精确相等（读数锚点见下）。
7. **口径对齐表**：页面底部，透明列出全部指标公式（如 花费工时(AC)=产出类需求花费+非产出类需求花费；CPI=产出类需求产出÷产出类需求花费）+ 已知数据质量问题（口径差异字段）——**跨模块核对存疑时优先翻这张表**，比自行盲猜口径更快更准。

### 读数锚点（数据正确性校验）

- 看板内部：headline（标准/花费/产出/非产出/范围扩张）加总 == 各项目明细逐条求和；CPI/告警计数公式可逆向验证。
- 跨表源数据：单项目 标准/花费/初始/新增/变更/产出 六项 == `project/get_project_list` 同项目行 `standard_hour/consumed_hour/origin_hour/new_hour/change_hour/done_hour`。
- 跨模块（谨慎对照，见下方陷阱）：本看板「产出类需求花费」== `cost_compare.algoA.actualHours`（计算路径相同，已验证一致）。

### 陷阱

- ⚠️ **本看板「产出工时(EV)」与 `cost_compare.algoB`「产出类型工时」同用"产出"字样但计算路径不完全同源**（两项目实测差值方向不一致，非人群子集关系）——两处功能各自独立定义"产出"边界，均无计算错误，不要武断判其中一方是 BUG（V2.3.3 报告 R1，建议产品侧统一口径或互相加说明）。
- ⚠️ 跨模块对同名指标存疑时，优先查页面自带「口径对齐表」反推，比自己盲猜「人员维度/需求维度」更准更快（该表会如实暴露主表与明细的填报时差字段）。
- ⚠️ 测试环境数据实时漂移（开发活跃），对账要看板与源头**同一时刻**取数比较，数值会随时间变化不可死记。
- 出定妆图/大数据量验证同上（headless + storageState；切「年」周期可看到 60+ 在统计项目验证渲染健壮性）。
