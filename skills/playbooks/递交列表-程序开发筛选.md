# 递交列表-程序开发人员筛选【只读】

> 一句话：在递交列表按"程序开发"人员筛出其负责的递交记录，供程序侧按人拉取数据。

- **入口**：递交 → 递交列表 → 筛选区「程序开发」下拉（与选择场景组/PM/行业线并列）
- **路由**：`/OPStestList/OPStestList_list`
- **适用/触发**：程序侧定时按人拉取递交明细；QA/PM 按程序开发人员核对递交进度

## 操作步骤（真实 UI）

1. 导航到 `/OPStestList/OPStestList_list`，等 `.el-table__header` 出现
2. ⚠️ **先设日期范围**（列表默认只筛当天，直接筛会空）：`.el-range-input` 两个输入分别 `fill('2026-01-01')`+`Enter`、`fill('2026-12-31')`+`Enter`
3. 点 `input[placeholder="程序开发"]` 打开下拉，选目标人员（`.el-select-dropdown__item:visible`）
4. 点「搜索/查询」按钮（或选中即触发）
5. 读结果：表格「程序开发」列应全为所选人员；`共 N 条` 为真子集

## 可直调接口（免 UI 快路径）

- `GET /manage_api/project_publish/get_list?begin=YYYY-MM-DD+00:00:00&end=YYYY-MM-DD+23:59:59&limit=99999&page=1&chengxu_people=<uid>`
  - `chengxu_people` = 程序开发人员 user_id（如龙顺波=79）；返回该人负责递交，为不带该参全量的真子集
  - 边界：非法 `chengxu_people=abc` 不 5xx；缺省则不按程序开发过滤
  - 响应 Laravel 分页：列表在 `data.data`
- 定时任务：直接用此接口按 uid 拉取，无需 UI

## 读数 / 断言锚点

- 列表主体：`.el-table__body tr`
- 程序开发列：表头 `.el-table__header th` 找「程序开发」列序，对应 `td`
- 总数：`共 (\d+) 条`

## 已知坑

- ⚠️ 列表默认只筛当天 → 不设日期范围会得空列表（P + 筛选纪律）
- ⚠️ 日期 `fill` 不触发内部提交，需接 `Enter`；或走 vm form+search
