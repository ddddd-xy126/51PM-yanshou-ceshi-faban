# 项目概览-预估营收时间【只读】

> 一句话：在项目概况时间轴/基本信息查看项目预估营收时间（精确到月）。

- **入口**：项目 → 项目概况 顶部时间轴「预估营收」节点；或「项目信息」tab 展开后「基本信息」→「预估营收时间」
- **路由**：`/project/project_detail?projectId=N`
- **适用/触发**：PM/销售运营按项目盘点营收计划节奏

## 操作步骤（真实 UI）

1. 导航到 `/project/project_detail?projectId=N`，等页面渲染
2. 顶部时间轴读「预估营收」节点值（YYYY-MM，无值显 —）：开工令 → 实际开工 → 初版递交 → 终版递交 → **预估营收** → 实际营收
3. 如需看基本信息字段：点 `[role=tab]:has-text("项目信息")` 展开 →「基本信息」子面板「预估营收时间」
4. 编辑：`el-icon-edit-outline` → 项目编辑表单 `/project/project_form/N`，编辑器 placeholder「选择预估营收月份」

## 可直调接口（免 UI 快路径）

- `GET /manage_api/project/get_project_info?id=N` → `data.info.plan_income_date`（YYYY-MM 月精度）
  - 另有 `income_date`（实际营收）、`is_income`（营收状态）
  - 不存在 id 不 5xx
- 定时任务：直接读 `plan_income_date`

## 读数 / 断言锚点

- 时间轴节点文本：`document.body.innerText` 含「预估营收」+ 月份值
- 基本信息字段：展开项目信息 tab 后 innerText 含「预估营收时间」
