# 项目特殊事项提醒【写】

> 一句话：给项目设置「特殊事项需同步」提醒，保存后项目列表项目名旁出现提示图标，全员点击即可查看提醒详情。典型 AI 复用场景：「给某项目挂一条全员可见的注意事项」。
>
> ⚠️ **写操作**：会修改项目信息（编辑表单整表校验）；提交前把「项目 + 提醒内容」给用户 AskUserQuestion 确认。

## 参数

| 参数 | 示例 | 说明 |
| --- | --- | --- |
| `env` | `test`（默认） | 测试 `10.67.8.183:7777` |
| `project` | `工业制造仿真优化智能决策平台` | 目标项目名（按名走 `get_project_list` 取 id）|
| `remind` | `本项目需同步关注递交时间轴` | 特殊事项提醒内容 |

## 入口

- **入口**：项目 → 项目列表 → 行内「编辑」→ 项目编辑表单「特殊事项需同步」字段；保存后「项目列表-项目名称」旁 `i.el-icon-warning`（tooltip「查看特殊事项」）→ 点击弹详情
- **路由**：编辑表单 `/project/project_form/{projectId}`；列表 `/project/project_list`
- **等待锚点**：表单 `waitForTimeout(2500)`；列表 `waitTableSettled`
- **进站**：先按 [../README.md](../README.md) Tab 复用

## 操作步骤（真实 UI）

1. 取项目 id：`GET /manage_api/project/get_project_list?page=1&limit=20`，按项目名匹配取 `id`
2. `goto /project/project_form/{id}`（⚠️ 列表编辑图标在 fixed-right 列，click 常被固定列拦截，取 id 直达 URL 绕开，台账 P-12）
3. 找「特殊事项需同步」form-item（是/否单选）→ 选「是」→ 下方条件展开「特殊事项提醒」textarea
4. 填提醒内容 → 点表单底部「更新」提交
5. 回 `/project/project_list` → 目标项目名旁出现 `el-icon-warning` → 点击 → 详情弹窗「特殊事项 · {商机号}」显示提醒文本 +「我知道了」

## 步骤

### 1. 取 id 直达编辑表单，选「是」展开提醒并填写

```js
// 选「是」需先点否再点是触发条件渲染
const it=[...document.querySelectorAll('.el-form-item')].find(x=>/特殊事项需同步/.test(x.querySelector('.el-form-item__label')?.innerText||''));
const radios=it.querySelectorAll('.el-radio'); radios[1].click(); await sleep(300); radios[0].click(); await sleep(500);
const set=(el,v)=>{const d=Object.getOwnPropertyDescriptor(Object.getPrototypeOf(el),'value');d.set.call(el,v);el.dispatchEvent(new Event('input',{bubbles:true}));el.dispatchEvent(new Event('change',{bubbles:true}));};
set(document.querySelector('textarea[placeholder="请输入特殊注意事项"]'), remind);
```

### 2. 提交（⚠️「更新」按钮被 form-columns 遮挡 → JS 原生 click）

```js
[...document.querySelectorAll('button')].find(b=>b.innerText.trim()==='更新')?.click();
// 成功 toast「项目编辑成功」；若报「请检查表单填写是否正确」= 有其它必填项空（如场景美术），补齐后再提交
```

### 3. 列表验证图标 + 详情（图标在 fixed 列 → JS click）

```js
const icon=document.querySelector('.el-table__fixed tbody tr .multi_package_icon'); // class 名沿用，tooltip=「查看特殊事项」
icon.click();  // 弹「特殊事项 · SJ号」详情框，显示提醒文本
```

## 🚨 防手滑（写操作强制）

- 编辑表单**整表校验**：原项目缺其它必填项（场景美术等）需一并补齐才能保存——补最小合规值，别乱改无关字段
- 提交前 AskUserQuestion 确认「项目 + 提醒内容」；测试环境可直接提交、不清理，内容带版本前缀

## 可直调接口（免 UI 快路径）

- 读项目：`GET /manage_api/project/get_project_info?id={id}`（⚠️ 实测**不直接返回**特殊事项字段值，取数另有通道，判断有无提示图标以列表 UI 为准）
- 保存：项目编辑走项目更新接口（POST 完整项目表单）

## 读数 / 断言锚点

- 编辑表单字段存在：`.el-form-item__label:text-is("特殊事项需同步")`；条件提醒框 `textarea[placeholder="请输入特殊注意事项"]`
- 列表提示图标：项目名单元格 `i.el-icon-warning`（tooltip「查看特殊事项」）；详情弹窗 `.el-dialog` 含「特殊事项」+ 提醒文本

## 已知坑

- ⚠️ 固定列/固定表头图标点击被拦截 → 取 id 直达 URL / JS 原生 click（台账 P-12）
- ⚠️ 编辑表单整表校验，缺其它必填项时需补齐才能保存
- ⚠️ 提醒文本仅在「特殊事项需同步=是」时渲染与生效；`get_project_info` 不回该字段值
