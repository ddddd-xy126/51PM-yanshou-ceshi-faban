# 项目问题动态（提出-跟踪-处理闭环）【写】

> 一句话：在项目动态创建「项目问题」并关联需关注人员，问题以卡片展示、可筛选/编辑/删除/快捷处理，需关注人员在「我的地盘-未解决项目问题」集中查看并处理，形成闭环。V2.3.0 新增。

- **入口**：项目 → 项目动态（`/project/project_moment?projectId=N`）→「添加动态」→「问题动态」tab；我的地盘 → 我的仪表盘顶部卡片「未解决项目问题」→「与我相关的项目问题」弹窗
- **路由**：`/project/project_moment?projectId=N`（创建/展示）· `/my_board/main/main`（闭环查看入口）
- **适用/触发**：记录项目风险问题、跟踪处理进度；需关注人员集中处理与自己相关的未解决问题

## 操作步骤（真实 UI）

### A. 创建项目问题（项目动态侧）

1. 导航 `/project/project_moment?projectId=N`，等 `.el-menu-item` 出现；关公告（helpers `dismissAnnouncement`）
2. 点「添加动态」按钮 → 弹窗三 tab（会议动态/风险动态/问题动态）
3. 点「问题动态」tab
4. 填表单（必填带 *）：
   - *问题类型：下拉选（需求变更/进度延期/资源不足/质量问题/沟通协作/技术难题/其他）
   - *问题描述：textarea 输入
   - 问题截图：可选，Ctrl+V 粘贴
   - *影响程度：radio 低/中/高（默认低）
   - *需关注人员：远程搜索 el-select，输入姓名（如「邓欣羽」）→ 点候选项。⚠️ 关联本人后本人在「我的地盘-未解决项目问题」可见（闭环关键）
   - 解决状态：radio 未解决（默认）/已解决/无需解决
   - 解决方案 / 解决时间：可选（选「已解决」后解决时间自动填今天）
5. 点「提交」→ Toast「添加成功」，卡片出现在动态时间线，顶部「问题 N」/「未解决 N」计数 +1

### B. 卡片操作（筛选/快捷处理/编辑/删除）

- **筛选**：顶部点「问题」/「未解决」/「已解决」等标签，卡片按类型/状态过滤
- **快捷处理（闭环）**：卡片「处理」→「处理问题」弹窗改解决状态=已解决 + 填解决方案 → 保存「处理已保存」→ 卡片状态实时更新、未解决计数 -1
- **编辑**：卡片编辑图标 →「编辑动态」弹窗（回显全字段）→ 改 → 提交「编辑成功」
- **删除**：卡片删除图标 → popconfirm「确定删除吗?」→ 是 →「删除成功」

### C. 我的地盘闭环查看（需关注人员侧）

1. 导航 `/my_board/main/main`，等 `li.el-menu-item`
2. 顶部卡片「需关注 N 个 未解决项目问题」→ **真实点击**（⚠️ JS click 不触发，用 click_element 或点 `.el-col:has-text("未解决项目问题")`）
3. 弹「与我相关的项目问题」弹窗：集中展示需关注=本人的问题卡片
4. 弹窗内可「按项目搜索」（输入框）、「添加问题」（按钮）、对卡片查看/编辑/删除/处理

## 可直调接口（免 UI 快路径）

- 列表：`GET /manage_api/project_moment/get_list?project_id=N&module=problem&page=1&limit=100` → Laravel 分页，**列表在 `data.data`**；非法 module 优雅返回不 5xx
- 创建：`POST /manage_api/project_moment/add`，payload：
  ```json
  { "type":"质量问题", "content":"问题描述", "risk_level":"中", "status":"未解决",
    "user_ids":[475], "user_id":[475], "remark":"", "create_time":"", "create_by":null,
    "create_name":"", "module":"problem", "project_id":"6644" }
  ```
  → code 0；`user_ids` = 需关注人员（含本人则我的地盘可见）
- 幂等造数助手：`regression/tests/helpers.js` 的 `ensureProblemMoment(request, {projectId, marker, type, riskLevel, status, user})`

## 读数 / 断言锚点

- 落库字段：`module=problem` / `type`(问题类型) / `risk_level`(影响程度) / `status`(解决状态) / `user_ids`(需关注人员) / `content` / `project_name`
- 卡片区：顶部筛选计数「全部/会议/风险/问题/未解决/已解决」；卡片含 类型+影响+状态+需关注+处理/编辑/删除
- 我的地盘：`/my_board/main/main` 卡片文本「未解决项目问题」；弹窗标题「与我相关的项目问题」

## 陷阱

- ⚠️ 需关注人员是远程搜索 el-select，输入触发候选；无输入不出选项。
- ⚠️ 我的地盘「未解决项目问题」卡片 JS click 不触发路由/弹窗，必须真实点击。
- ⚠️ V2.2.9 曾有「卡片编辑/删除按钮全禁用、点卡无详情、无法闭环」缺陷，V2.3.0 已修复；若复现按钮禁用即为回归。
- ⚠️ get_list 响应是 Laravel 分页，列表在 `data.data` 不是 `data`。
